## About page
The about page works as a welcome screen for first time visitors. The page should be used to engage with first time visitors

## Acceptance criteria
Create a route to /about
Makea template and work with the UX team for an 'eye-candy' approach. they will provide text, format and content
Create a button that redirects to the login page
Follow current design principles

## DONT
Re-write any logic. The marketing team wil distribute QR codes pointing to ALKACHOF_URL/about so the agent doesnt need to rewrite the routing logic
